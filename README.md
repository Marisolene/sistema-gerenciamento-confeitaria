# sistema-gerenciamento-confeitaria
# Sistema de Gerenciamento de Pedidos para Confeitarias

## Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema simples para auxiliar pequenas confeiteiras no gerenciamento de pedidos e clientes.

A solução busca facilitar a organização das encomendas, centralizando informações que atualmente são registradas por meio de conversas no WhatsApp e anotações em cadernos.

## Funcionalidades do MVP

- Cadastro de clientes.
- Cadastro de pedidos vinculados aos clientes.
- Consulta de pedidos cadastrados.
- Atualização do status dos pedidos.

## Tecnologias utilizadas

- Python 3.12
- Flask
- HTML5
- CSS3
- SQLAlchemy
- SQLite

## Objetivo

Desenvolver uma solução prática e acessível que contribua para a organização da rotina de pequenas confeiteiras.

## Contexto acadêmico

Projeto desenvolvido na disciplina Projeto de Software, do curso de Análise e Desenvolvimento de Sistemas.
